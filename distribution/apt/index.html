Keep Clawd up to date
with APT.

Add the official source once. Then use your system package manager for future .deb updates.

Published version: {{VERSION}} · amd64 / x86-64

For Debian 12/13 and Ubuntu 22.04/24.04 on 64-bit Intel or AMD machines. Check with dpkg --print-architecture: it must say amd64. AppImage users keep Clawd’s in-app updater and do not need this source.

Already have the source?

Quit Clawd, run these commands, then reopen it:

sudo apt update
sudo apt install --only-upgrade clawd-on-desk clawd-apt-source

System update tools can also offer these updates. Adding this source does not enable unattended upgrades.

One-time setup · new and existing users

Existing .deb installations, including 1.3 and 1.4, can adopt this source directly. You do not need to make the old in-app updater work first. Your normal Clawd settings stay in your user profile.

1. Quit Clawd

An older version may ask to install an already downloaded update when quitting. Cancel that authorization prompt and continue below.

2. Download and check the source package

Download {{BOOTSTRAP}} to your Downloads folder. This small package contains the source configuration, a scoped public signing key, and package restrictions. It contains no install scripts.

cd ~/Downloads
printf '%s  %s\n' '{{BOOTSTRAP_SHA256}}' '{{BOOTSTRAP}}' | sha256sum --check

Continue only if the check says OK. The HTTPS guide is the initial trust entry point; this checksum detects a changed download, not a compromise of this entire website.

3. Add the source and install or upgrade Clawd

sudo apt install ./{{BOOTSTRAP}}
sudo apt update
sudo apt install clawd-on-desk

4. Reopen Clawd

Future .deb notifications open this guide. Clawd will not run a privileged installer or install a .deb when you quit.

Verify the signing key

Primary fingerprint: {{FINGERPRINT}}

Inspect the public key with gpg --show-keys --with-fingerprint clawd-on-desk.asc. Compare the full fingerprint with the maintainer’s reviewed activation record before first installation. APT uses this key only for this source via Signed-By; it is not added to global trust.

Remove or temporarily disable the source 
sudo apt purge clawd-apt-source
sudo apt update

This keeps Clawd installed. Use purge: plain apt remove retains the configuration and trust key, leaving the source active without future key updates. To pause updates, add Enabled: no to /etc/apt/sources.list.d/clawd-on-desk.sources. Package upgrades preserve that choice.

The pin in /etc/apt/preferences.d/clawd-on-desk.pref permits only clawd-on-desk and clawd-apt-source. Its restriction covers the entire rullerzhou-afk.github.io hostname, including other paths.

New version missing, expired key, or source unavailable?

A release notification may arrive before source publication completes. Check apt-cache policy clawd-on-desk, wait a few minutes, then retry sudo apt update. Refresh indexes if an older package URL returns 404.

If signature verification fails, stop and check this guide and the official repository for key renewal instructions. Do not use trusted=yes, disable signature checks, or ignore authentication errors. Before expiry, normal clawd-apt-source upgrades can deliver an overlapping key update; after expiry, download and verify a newly versioned source package through this guide.

You can keep the current app or temporarily disable the source. If you prefer manual updates, download the matching .deb from GitHub Releases and install it with sudo apt install ./Clawd-on-Desk-VERSION-amd64.deb after quitting Clawd.

首次接入 · 新用户和旧用户通用

已安装 1.3、1.4 等旧版 .deb 的用户可以直接迁移，不必先修好旧版应用内更新。原有用户配置会保留。

1. 退出 Clawd

旧版可能在退出时请求安装此前下载的更新。取消该授权提示，再继续以下操作。

2. 下载并校验软件源接入包

将 {{BOOTSTRAP}} 保存到下载文件夹。这个小包只包含软件源配置、公钥和包范围限制，没有安装脚本。

cd ~/Downloads
printf '%s  %s\n' '{{BOOTSTRAP_SHA256}}' '{{BOOTSTRAP}}' | sha256sum --check

只有显示 OK 才继续。若下载目录不同，请替换第一行。首次信任来自本 HTTPS 页面；校验值可以发现下载文件被修改，不能防范整个网站被攻破。

3. 添加软件源并安装或更新 Clawd

sudo apt install ./{{BOOTSTRAP}}
sudo apt update
sudo apt install clawd-on-desk

4. 重新打开 Clawd

以后 .deb 的更新提示会打开本指南，Clawd 不会自行运行提权安装器，也不会在退出时安装 .deb 更新。

公钥核验与信任范围

主密钥指纹：{{FINGERPRINT}}

下载公钥，运行 gpg --show-keys --with-fingerprint clawd-on-desk.asc，并与维护者审核过的启用记录核对完整指纹。APT 通过 Signed-By 将此密钥限制于本软件源，不添加全局信任。

移除或暂时停用软件源 
sudo apt purge clawd-apt-source
sudo apt update

这会移除软件源和公钥，保留 Clawd 本体。必须使用 purge；普通 apt remove 会保留配置和信任，软件源仍启用，却无法再收到公钥更新。若只想暂停，在 /etc/apt/sources.list.d/clawd-on-desk.sources 中添加 Enabled: no，升级会保留这一设置。

/etc/apt/preferences.d/clawd-on-desk.pref 只允许安装 clawd-on-desk 和 clawd-apt-source。限制覆盖整个 rullerzhou-afk.github.io 主机名，包括其下其他路径。

找不到新版、密钥过期或软件源暂时不可用

应用通知可能早于软件源发布。可用 apt-cache policy clawd-on-desk 查看候选版本，稍等几分钟再运行 sudo apt update。旧包地址返回 404 时，也应先刷新索引。

签名校验失败时请停止安装，查看本指南及官方仓库的密钥更新说明。不要使用 trusted=yes、关闭签名检查或忽略认证错误。密钥过期前，正常更新 clawd-apt-source 可获得交叠的新密钥；已过期时，请从本指南重新下载、核验并安装新版本接入包。

也可以暂时保留当前版本或停用软件源。若选择手动更新，从 GitHub Releases 下载相应的 .deb，退出 Clawd 后用 sudo apt install ./Clawd-on-Desk-VERSION-amd64.deb 安装。
