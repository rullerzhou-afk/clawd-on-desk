## 原失败的处理

- Windows 不默认授予文件符号链接创建权限。目录链接改用真实 junction。拒绝链接的文件夹具优先创建真实符号链接，仅在 Windows EPERM 时使用 lstat 可识别的 junction；外部目标和原所有权断言保持完整。指向文件的 Windows junction 不可解析，因此另用 Ubuntu 验证可读取的真实文件符号链接拒绝场景，不能将两者当作同一种 OS 解析能力。
- Ubuntu 真实文件链接组：185 项，184 通过、0 失败、1 项原有条件跳过。Windows 相关组分别为 197 通过/0 失败和 179 通过/0 失败。
- Antigravity 的路径断言修正为空格路径必须带引号，生产命令保持不变。
- Windows 默认同时运行两个测试文件，支持显式 `CLAWD_TEST_CONCURRENCY` 覆盖，避免 PowerShell/Electron 启动争抢资源。实际 5 秒 hook 时限不变；测试运行器契约 13 项通过。
- 隐藏图形测试等待真实离屏 compositor frame 后才截图，解决 UnknownVizError。1x、1.25x、1.5x 下原有像素、透明层、几何与 SMIL 断言全部保留并通过。
